# Lab

A practice environment for the crew, with faults injected on purpose ("drills") so every diagnosis can be scored against a known root cause.

- **Docker Compose lab (Sprint 1, planned):** web server, application server, MySQL, RabbitMQ, Memcached and an ETL job, reachable over SSH. Runs on a laptop and in CI.
- **Vagrant lab (optional, from v1):** the original five-VM lab (`vagrant/`), kept for anyone who wants full virtual machines. Its passwords are the public Vagrant defaults and must never be used outside a local lab.
