# Licensing in plain English

Wheelhouse is **source-available** under the [Business Source License 1.1](LICENSE). It is not "open source" by the OSI definition, and this project does not call itself that.

This page is a summary. The [LICENSE](LICENSE) file is what applies.

## Free

- Reading, copying, modifying and sharing the code.
- Any non-production use: learning, testing, evaluating, demos, development.
- Production use by an individual for personal, learning or other non-commercial purposes.
- Production use by schools, colleges and universities for teaching or research.
- Production use by registered non-profits for their own non-commercial work.

## Needs a commercial licence

- A company running Wheelhouse in production, to operate, monitor or migrate its own systems.
- A service provider (IT services, MSP, consultancy) using Wheelhouse to run or migrate systems for its clients.
- Offering Wheelhouse, or a product built on it, as a paid service.

To ask about a commercial licence, open an issue titled "Commercial licence" on this repository.

## Every version becomes open source

Each version converts to the Apache License 2.0 four years after it is first published. Earlier versions do not wait for later ones.

## History

The original proof of concept (tag `v1-poc`, May 2025) was published under the MIT licence, and that tagged code stays under MIT. Everything from the Wheelhouse rebuild onwards is under the Business Source License 1.1.

## Dependencies

Wheelhouse depends on open source packages under their own licences (for example Apache-2.0, MIT, BSD). This licence covers Wheelhouse's own code only.
